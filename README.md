# NODO

[![Release](https://jitpack.io/v/scarlettychen/NODO.svg)](https://jitpack.io/#scarlettychen/NODO)
[![Downloads (week)](https://jitpack.io/v/scarlettychen/NODO/week.svg)](https://jitpack.io/#scarlettychen/NODO)
[![Downloads (month)](https://jitpack.io/v/scarlettychen/NODO/month.svg)](https://jitpack.io/#scarlettychen/NODO)

NODO is a lightweight FTC autonomous framework for teams without odometry pods. It combines battery voltage compensation, IMU gyro correction, and time-based movements for reliable autons on mecanum or tank.
